# 发布文章

每篇文章位于 `articles/<文章目录>/`，源稿是 `index.md`，文章信息写在 `article.json`，图片、GIF 和视频放进自己的 `assets/` 文件夹。

运行 `python3 scripts/build.py` 后，`site/index.html` 是文章合集首页，`site/<文章目录>/index.html` 是单篇阅读页。构建同时会在 `dist/<文章目录>.zip` 生成该篇文章的 Markdown、HTML 和素材包。

发布 Markdown 到博客平台时，按平台要求上传本篇 `assets/` 中的媒体并调整路径。平台不支持内嵌视频时，可以删除 `<video>` 标签，改用平台的视频上传组件。保留素材来源说明，并核对所引用数据的使用条款。
