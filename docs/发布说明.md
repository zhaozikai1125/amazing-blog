# 发布文章和素材

源稿位于 `articles/egodemo-learning-log.md`。发布到博客平台时，按平台要求上传 `assets/` 中的图片，并调整 Markdown 图片路径。

文章中的 GIF 和 MP4 内容相同，可以择一发布。平台不支持内嵌视频时，删除 HTML 视频标签，改用平台的视频上传组件。

配图和动画为原创教学素材，动画使用合成数据。发布时保留这项说明。发布素材包由 `python3 scripts/build.py` 生成在 `dist/`。

文章不包含 EgoDemo 原始视频、真实姿态轨迹、逐条采集标识或服务器连接信息。引用原始数据时，请从官方入口获取并核对当时的使用条款。
