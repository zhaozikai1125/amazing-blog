# 新增与发布文章

每篇文章放在 `articles/<文章目录>/`，目录里包含：

- `article.json`：标题、日期、摘要和标签，供合集首页展示。
- `index.md`：文章正文。
- `assets/`：这篇文章专用的图片、GIF、视频。
- `source_evidence/`：需要随文章保留的汇总依据（可选）。

把 `articles/_template/` 复制一份，改成新的英文目录名，再编辑以上文件。图片在正文中的引用方式是 `![说明](assets/图片名.png)`。

安装依赖后运行 `python3 scripts/build.py`：

- `site/index.html` 更新为全部文章的合集首页。
- `site/<文章目录>/index.html` 是对应文章的阅读页，配套素材会一起复制过去。
- `dist/<文章目录>.zip` 是该篇文章的发布包。

发布 Markdown 时，按博客平台要求上传当前文章 `assets/` 里的媒体并调整路径。视频可用 GIF 替代，也可上传 MP4 后用平台的视频组件嵌入。
