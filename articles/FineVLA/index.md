# FineVLA 项目调研报告

> **FineVLA：面向可操控视觉-语言-动作策略的细粒度指令对齐**
> Fine-Grained Instruction Alignment for Steerable Vision-Language-Action Policies
>
> 出品方：香港大学 XLANG Lab × 阿里巴巴 Qwen Team
> 项目主页：https://finevla.xlang.ai/
> 报告日期：2026-10-27
> 说明：本文基于公开报道与项目页面信息整理，部分数值在不同信源中存在出入（见文末「待核实项」），请以论文原文与官方仓库为准。

## 一、一句话概述

FineVLA 是由港大 XLANG Lab 与阿里 Qwen 团队联合推出的开源框架，旨在解决 VLA（视觉-语言-动作）模型"语言监督粒度太粗"的长期痛点。它不追求更大的模型，而是从数据层入手，将 10 个开源数据集的约 97 万条异构轨迹压缩、清洗并标注为 4.7 万条"过程级"细粒度指令，进而训练出能听懂"用哪只手、从哪边接近、抓哪个部位"的可控策略。框架包含数据工具、评测基准、专用 VLM 标注器与策略训练四部分，代码、模型与基准均已开源。

## 二、研究背景与动机

### 2.1 现有 VLA 的"听话"困境

当前 VLA 模型已能根据自然语言完成抓取、放置等任务，但语言监督通常只到**目标级（goal-level）**：

| 场景 | 数据集常见标注 | 缺失的执行细节 |
|---|---|---|
| 拿勺子 | "拿起勺子" | 左臂还是右臂、绕障还是直线 |
| 抓杯子 | "把杯子拿过来" | 抓杯身还是杯柄、从上抓还是侧抓 |
| 装配 | "装上零件" | 接近角度、接触部位、旋转方向 |

同一任务的多条轨迹往往共享同一条指令，造成**监督歧义**：模型能学到"要成功"，却学不到"怎么成功"。相比之下，图像/视频生成领域早已证明细节描述直接决定可控性，而机器人策略学习长期缺少对应的基础设施。

### 2.2 三个核心挑战

1. **缺基础设施**：没有从异构数据到细粒度标注的统一工具链，各团队重复造轮子；
2. **缺评测与标注器**：缺少衡量机器人细粒度视频理解的基准，也缺少低成本可扩展的自动标注器；
3. **缺系统性证据**：细粒度语言是否真的提升策略学习、如何与原指令混合最优，此前缺乏受控实验。

FineVLA 逐一回应了这三点。

## 三、整体架构：数据—模型—评测—策略闭环

```
                    ┌──► RoboFine-Bench（评测基准）
FineVLA-Tool ──► FineVLA-Data ──┤
（数据流水线）   （47K 细粒度指令）├──► RoboFine-VLM（可扩展标注器）
                                 │
                                 └──► FineVLA-Policy（可控 VLA 策略）
                                              │
                              RoboTwin 仿真 + Cobot Magic 真机双臂
```

核心理念：**语言监督既要指定"做什么"，也要指明"怎么做"**；且二者不是替代关系，而是互补关系。

## 四、四大核心组件

### 4.1 FineVLA-Tool：从 97 万条轨迹到细粒度数据

四阶段流水线：

| 阶段 | 内容 | 关键处理 |
|---|---|---|
| S1 收集与格式转换 | 汇聚 BridgeData-V2、DROID、BC-Z、RT-1、RoboMIND 等 **10 个开源数据集共 972,247 条轨迹** | 统一转换为 LeRobot 2.1 格式 |
| S2 规范化与清洗 | 动作-状态表示统一 | 全部转为**绝对坐标 + 归一化四元数**旋转；DTW 距离门控剔除损坏/不一致轨迹 |
| S3 聚类与采样 | 去冗余 | 基于 **DTW 计算轨迹相似度 + 层次聚类**，逐簇选取代表样本；972K → **47,159 条**，冗余降低约 95%，保留策略多样性 |
| S4 十维细粒度标注 | 步骤级描述生成 | 先由 Qwen3.5-Plus 生成，再经**人工审核验证**，产出 FineVLA-Data |

**十维标注模式（10-D Schema）** 覆盖操作的关键执行因素：动作序列、主动执行者（左/右臂）、目标物体、初始/最终配置、接触与接近方式、轨迹与朝向、物体交互、失败与恢复、本体运动等。

效果：平均指令长度由 **9.3 词 → 96.8 词，信息密度提升 10.4 倍**。

> 这一设计的巧妙之处：DTW 聚类去重大幅降低了后续人工标注成本，使"高质量细粒度标注"在工程上变得可行。

### 4.2 RoboFine-Bench：细粒度动作理解基准

| 项目 | 规格 |
|---|---|
| 视频数 | 500 段（来自 10 个数据集） |
| 机器人形态 | 覆盖 32 种 embodiment |
| 原子事实 | 约 1.08 万～1.16 万条人工审核事实（各样本平均约 4.3 步） |
| 数据隔离 | 与训练集**严格不重叠** |
| VQA 轨道 | 1,030 题，覆盖 10 个维度，聚合为三轴：实体与场景定位（Grounding）、动作与运动理解（Action）、交互与状态推理（State） |
| Caption 轨道 | 生成步骤级细粒度描述，由 LLM 评判一致性 / 覆盖率 / 反幻觉；分 **Easy**（提供原任务指令）与 **Hard**（仅凭视觉推理）两模式 |

Easy/Hard 双模式的设计用于区分模型是"真正理解了执行过程"还是"依赖语言先验"。

### 4.3 RoboFine-VLM：机器人专用的可扩展标注器

通用 VLM 常遗漏接触区域、运动路径、物体歧义区分等执行细节。为此作者在 FineVLA-Data 上做全参数微调：

| 配置项 | 参数 |
|---|---|
| 基座 | Qwen3.5-VL-397B-A17B |
| 微调方式 | 全参数监督微调 |
| 训练数据 | 47,159 条人工验证的视频-指令对 |
| 硬件 | 256 × H200，全局 batch 512 |
| 学习率 | 7e-6 → 7e-7 线性衰减 |
| 耗时 | 约 40 小时 |

输出为**与动作时序对齐的步骤级描述**，覆盖全部 10 个控制维度，可直接作为未来新轨迹的自动标注器。

> **重要说明**：**所有策略实验使用的细粒度监督均来自人工验证标注，而非 RoboFine-VLM 生成**。该模型定位为"未来数据扩增工具"，其质量在 RoboFine-Bench 上独立评估。

### 4.4 FineVLA-Policy：可控策略训练

**骨干与解码器**：以 Qwen3.5-4B 为视觉-语言骨干，采用 StarVLA 代码库的两种动作头：

- **StarVLA-OFT**：轻量 MLP 回归头，L1 损失并行预测连续动作片段；
- **StarVLA-GR00T**：双系统架构，VL 主干作 System 2，DiT 流匹配模块作 System 1。

**核心实验设计**：保持轨迹、动作、视觉观测完全不变，**只改变与每条轨迹配对的指令**，从而隔离出语言监督类型的纯效应。通过控制 FG（细粒度）与 Raw（原始目标级）在每个训练步的采样概率，扫描混合比例。

训练规模：预训练 100k 步 / 64×A100（batch 512），RoboTwin 微调 8×A100。

## 五、实验结果

### 5.1 RoboFine-VLM 在基准上达到 SOTA

| 指标 | RoboFine-VLM | 次优基线 |
|---|---|---|
| VQA 整体准确率 | **71.0%** | Gemini-3.1-Pro 62.1% / GPT-5.4 61.0% |
| 其中"动作与运动理解" | 68.4% | 58.4% |
| Caption Easy Overall | 88.0% | GPT-5.4 85.2% |
| Caption Hard Overall | **83.6%** | GPT-5.4 78.1% |

自动评分与 10 位人类评分者排序的 Pearson 相关性 > 0.97，说明 LLM-as-a-judge 评估可靠。

### 5.2 仿真：倒 U 型的"黄金混合比"

AlohaMix-OFT 在 RoboTwin 上的表现（FG:Raw 比例）：

| FG:Raw | Easy | Hard |
|---|---|---|
| Raw-only (0) | 71.8% | 71.4% |
| 1:2 | ↑ | ↑ |
| **1:1（最佳）** | **86.8% (+15.0)** | **82.5% (+11.1)** |
| FG-only | 78.4% | 76.1% |
| 2:1 / 4:1 | 回落 | 回落 |

三种设置（RDT-OFT、RDT-GR00T、AlohaMix-OFT）、跨架构与跨数据规模均呈现一致的**倒 U 型曲线**，峰值落在 FG 占比 33%～50% 区间。

### 5.3 真机：因子级可控性

在 Cobot Magic 桌面双臂平台上构造指令敏感任务（同一视觉场景下仅改变语言中的一个控制因素：颜色/姿态/接近方向/旋转方向/手臂选择）：

- FG:Raw=1:1 平均得分 **62.7/100**，Raw-only 仅 **49.9**；
- 单因子增益最大者：**姿态 +23、颜色 +18、接近方向 +18**——恰好是原始指令完全不提供的维度；
- OOD 组合（如训练中未出现的"左手操作右侧目标"）：Raw-only 得 0，混合后提升至 5～10/10，显示出**因子级泛化**能力。

成对对比可视化显示，模型能准确识别并执行仅由单一语言因素差异驱动的不同行为（顺时针/逆时针旋转、上抓/右抓、左手/右手等）。

### 5.4 三个消融发现

1. **细粒度监督缩小架构差距**：RDT 上 OFT 与 GR00T 的差距由 Raw-only 的 6.4/6.6 缩小至 FG-only 的 0.8/0.5，说明密集语言监督缓解了监督瓶颈，降低了对动作头设计的敏感度。
2. **FG 在更大数据上获益更多**：从 RDT 到 AlohaMix（约 13× 数据），FG-only 相对 Raw-only 的增益由 +1.4/+2.0 升至 +6.5/+4.7，表明细粒度是可扩展的监督维度。
3. **倒 U 型机理**：Raw 提供紧凑的任务语义（做什么），FG 提供执行约束（怎么做）。纯 Raw 缺指导，纯 FG 可能削弱对紧凑任务表达的泛化，适度混合两者兼顾。

## 六、贡献总结

1. **首个完整的可控 VLA 开源闭环**：涵盖数据构建工具、细粒度基准、可扩展标注器与可控策略配方，且全部开源。
2. **FineVLA-Data**：972K 异构轨迹 → 47K 人工验证的十维过程级指令，信息密度提升 10.4 倍，为社区提供了可直接复用的高质量语料。
3. **RoboFine-Bench**：500 视频 / 32 形态 / 万级原子事实，训练-测试严格隔离，填补了细粒度机器人视频理解评测的空白。
4. **实证结论**：细粒度监督不损害任务成功率且与之互补；最佳混合比 FG:Raw ≈ 1:1～1:2；细粒度语言可直接转化为因子级可控性与一定的组合泛化。

## 七、局限性与未来方向

| 局限 | 说明 |
|---|---|
| 验证范围有限 | 真机仅限桌面双臂平台与少量定向任务，更多具身形态待验证 |
| 组合泛化仍弱 | OOD 的 actor-target 绑定成功率仅 0～10/10 |
| 人在回路未消除 | RoboFine-VLM 仍需人工验证环节 |
| 安全性缺失 | 细粒度指令遵循缺少可行性与安全校验机制 |
| 算力门槛高 | 预训练 64×A100×48h、微调 8×A100×48h、VLM 训练 256×H200×40h，属实验室级投入 |

未来方向：提升组合泛化能力、扩展到更多形态（含人形与移动操作）、集成安全约束与可行性检查、探索端到端联合优化及跨领域泛化。

## 八、应用价值与落地场景

- **工业精密装配**：指定工具使用顺序、接近角度与接触部位；
- **物流仓储**：多品类抓取时约束接触点与抓取姿态；
- **医疗辅助**：器械传递中指定交接手与交接姿态；
- **服务与人机协作**：复杂场景下的递送与交互，支持自然语言的细节级指令；
- **数据工程侧**：FineVLA-Tool 流水线与 RoboFine-VLM 标注器可迁移至任意自有遥操作数据集，显著降低细粒度标注成本。

## 九、快速上手建议

1. 访问项目主页 https://finevla.xlang.ai/ 获取论文、代码与模型链接；
2. 若已有遥操作数据：优先跑通 **FineVLA-Tool** 的格式统一与 DTW 去重流程，再按需接入十维标注；
3. 若关注策略效果：从 **FG:Raw = 1:1** 起步做基线，再向 1:2 方向扫描，避免直接使用 FG-only；
4. 若需评测细粒度理解能力：使用 **RoboFine-Bench** 的 Easy/Hard 双模式，Hard 模式更能反映真实理解水平；
5. 资源受限时：可只使用开源的 FineVLA-Data 与基准，不必复现 RoboFine-VLM 的全参数微调。
